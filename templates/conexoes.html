Power BI

O Power BI puxa os dados daqui no horário que você configurar

Verificando...

No Power BI: Obter dados → Web → Avançado. Cole a URL e acrescente o cabeçalho X-API-Key com a chave do sistema. Esta é a única URL do sistema: ela devolve o histórico inteiro, sem filtro de período. O recorte de mês e ano é feito dentro do Power BI, com segmentação — a fonte se configura uma vez e nunca mais se mexe.

Base completa do sistema
As três tabelas que vêm dentro dela
CampoUma linha para cada
acompanhamentodia × unidade × bairro — agendamentos, exames, conversão, patologias
leadsdia × local × agência — leads recebidos e agendamentos
hora_a_horadia × unidade × atendente — agendamentos, comparecimentos, vendas, punições

Depois de colar a URL, o Power BI mostra um Registro com esses três nomes. Clique em acompanhamento → Para a tabela → expanda as colunas. Repita o processo para as outras duas, duplicando a consulta. São três tabelas, uma só chamada ao servidor.

! A tabela hora_a_hora leva nomes de atendentes com desempenho individual. A chave fica gravada dentro do arquivo .pbix — quem receber o arquivo passa a ter acesso a tudo isso.

Webhook

O sistema avisa um endereço externo a cada salvamento do Hora a Hora

Verificando...

Com a WEBHOOK_URL definida, cada salvamento do Hora a Hora dispara um POST com o retrato completo do dia daquela unidade. O envio acontece em segundo plano: o salvamento nunca fica esperando o destino responder.

Onde se configura

As chaves vivem no servidor, nunca no navegador

Easypanel → serviço connecting2 → Variáveis de ambiente. Depois de alterar, clique em Implantar para o sistema reler.

VariávelPara que serve
EXTERNAL_API_KEYlibera as rotas do Power BI. Sem ela, tudo responde 401.
WEBHOOK_URLendereço que recebe os avisos. Vazio = nada é disparado.
WEBHOOK_SECRETassina cada disparo para o destino conferir a origem.
WEBHOOK_DEBOUNCEsegundos mínimos entre dois avisos da mesma unidade e dia.
